## Implementation plan template (Step 4)

```markdown
## Implementation Plan: #{number} — {title}

### Summary
One-paragraph description of what will change and why.

### Affected Files
List every file to create, modify, or delete, with a short note per file.

### Implementation Steps
Numbered steps specific enough for an unfamiliar contributor to execute.

### Testing
Manual and automated verification steps.

### Risks & Edge Cases
Anything that could go wrong or needs special attention.

### Dependencies
Issues that must land first, or that this work unblocks.
```
