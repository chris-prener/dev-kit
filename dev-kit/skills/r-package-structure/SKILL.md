# R Package Structure

You are creating or maintaining a CRAN-style R package. This skill defines the canonical package layout, roxygen2-driven documentation, NAMESPACE management, usethis workflows, and quality checks.

## Activation

Activate when the user needs to create a new R package, restructure an existing project into package form, or understand package development conventions.

## Inputs

- **Required**: package name (must follow R naming rules: letters, numbers, dots; start with letter)
- **Optional**: whether the package will be published to CRAN or internal only
- **Optional**: whether to include compiled code (src/)

## Steps

### 1. Canonical package layout

```
<package-name>/
├── .github/
│   └── workflows/
│       └── R-CMD-check.yaml
├── .Rbuildignore             # Files excluded from package build
├── .gitignore
├── DESCRIPTION               # Package metadata (required)
├── LICENSE                   # License file
├── LICENSE.md                # Full license text
├── NAMESPACE                 # Export/import declarations (roxygen2-generated)
├── NEWS.md                   # User-facing changelog
├── R/                        # R source code
│   ├── package-name-package.R  # Package-level documentation
│   └── *.R                   # Function files
├── README.md                 # Package README (pkgdown home page)
├── inst/                     # Installed files (available at runtime)
│   └── extdata/              # External data files
├── man/                      # Documentation (roxygen2-generated, DO NOT EDIT)
│   └── *.Rd
├── data/                     # Package data (lazy-loaded .rda files)
├── data-raw/                 # Scripts that generate data/ files
│   └── DATASET.R
├── tests/
│   ├── testthat/
│   └── testthat.R
├── vignettes/                # Long-form documentation
│   └── getting-started.Rmd
├── renv.lock                 # Dev dependency lockfile
└── <package-name>.Rproj
```

```

BugReports: https://github.com/yourusername/mypackage/issues
```

### 3. NAMESPACE management

**Never edit NAMESPACE manually.** It is generated by roxygen2.

```r
# Regenerate NAMESPACE:
devtools::document()
```

**Export patterns in R source files:**

```r
#' @export
public_function <- function(x) { ... }

# NOT exported (internal helper):
internal_helper <- function(x) { ... }

#' @importFrom rlang .data
#' @importFrom cli cli_abort
NULL
```

**Rules:**
- Export only user-facing functions
- Use `@importFrom` for frequently-used external functions (avoids `::` in hot paths)
- Use `pkg::fun()` for infrequent external calls
- Never use `@import` (imports entire namespace — too broad)

### 4. Package-level documentation

Create `R/<package-name>-package.R`:

```r
#' @keywords internal
"_PACKAGE"

## usethis namespace: start
#' @importFrom rlang .data
## usethis namespace: end
NULL
```

### 5. usethis workflow shortcuts

```r
# Create package skeleton:
usethis::create_package("path/to/mypackage")

# Add common infrastructure:
usethis::use_testthat(edition = 3)
usethis::use_readme_md()
usethis::use_news_md()
usethis::use_vignette("getting-started")
usethis::use_pkgdown()
usethis::use_github_action("check-standard")

# Add dependencies:
usethis::use_package("dplyr", min_version = "1.1.0")
usethis::use_dev_package("lintr")

# Add data:
usethis::use_data(my_dataset, overwrite = TRUE)
usethis::use_data_raw("DATASET")

# Add a new R file with test:
usethis::use_r("utils_data")
usethis::use_test("utils_data")
```

### 6. Quality checks

```r
# Full R CMD check (the gold standard):
devtools::check()

# Quick check (skip vignettes, examples):
devtools::check(vignettes = FALSE)

# Check documentation:
devtools::document()
devtools::check_man()

# Check for common issues:
devtools::spell_check()
urlchecker::url_check()
```

**R CMD check must pass with 0 errors, 0 warnings, 0 notes** for CRAN submission. For internal packages, 0 errors and 0 warnings is the minimum bar.

### 7. Versioning

Follow semantic versioning:
- `0.0.0.9000` — development version (pre-first-release)
- `0.1.0` — first usable release
- `x.y.z` — MAJOR.MINOR.PATCH after first release

```r
# Bump version:
usethis::use_version("minor")  # 0.1.0 → 0.2.0
usethis::use_version("patch")  # 0.2.0 → 0.2.1
usethis::use_dev_version()     # 0.2.1 → 0.2.1.9000
```

### 8. .Rbuildignore

```
^\.github$
^renv$
^renv\.lock$
^.*\.Rproj$
^\.Rproj\.user$
^data-raw$
^docs$
^LICENSE\.md$
^_pkgdown\.yml$
^\.lintr$
```

## Outputs

- A complete R package directory meeting `R CMD check` standards
- Generated NAMESPACE and man/ pages
- Configured test and vignette infrastructure

## Success criteria

- `devtools::check()` passes with 0 errors, 0 warnings
- NAMESPACE is roxygen2-generated (no manual edits)
- All exported functions have complete roxygen2 documentation
- Package installs cleanly via `devtools::install()`
